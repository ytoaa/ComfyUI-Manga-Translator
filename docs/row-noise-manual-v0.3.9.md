# OCR 행 복구와 수동 통합 경로 — v0.3.9

## 305×270 실제 실패 입력

제공된 크롭은 가로 본문 10행, 왼쪽 점선과 종이 질감, 아래 페이지 번호다.
256/512 patch 시도에서 모두 반복 출력이 나왔으며 이 반복 거부는 유지해야 한다.
기존 행 투영은 작은 잡음까지 포함해 행 간격을 잇고 있었고, 복구 분석도 같은 문제를 가지고 있었다.
v0.3.8의 작은 성분 제외는 누락 경보에만 적용되어 있었다.

이제 행/열 복구 분석에서 8방향 연결 성분 8픽셀 미만을 제외한 뒤 기존의 간격/긴 행/여러 성분
검증을 수행한다. 인식 크롭에는 제외하지 않는다. 실제 입력에서 분석상 제외된 잡음 픽셀은 776개다.
`verified_rows`로 본문 10개와 페이지 번호 1개를 얻으며, 행 경계는
`0,22,45,67,90,113,136,158,182,204,231,270`이다.
82,350픽셀 모두 정확히 하나의 입력에 속하고 재조립 배열은 원본과 동일하다.

복구는 기존 두 patch 품질 시도 후에만 한 번 수행한다. 최대 16개 조각/영역 128작업, 자식 및
결합 문자열의 품질 검사와 지속 실패 중단은 유지한다. 진단에 분석 면적 기준/제외 픽셀 수가 남는다.
이 검증은 실제 픽셀 분할이며 실제 Hayai 인식 성공 증거는 아니다.

페이지 번호 조각의 `32`가 종이 잡음 때문에 다시 누락으로 막히는 경우도 확인했다.
누락 추정의 분석 면적 기준은 이제 관측된 최대 성분 면적의 20%를 사용하되 4~16픽셀로 제한한다.
큰 글자와 작은 종이 성분을 구분하면서 실제 2×2 작은 성분들로 된 누락 검사도 유지한다.
이 변경 역시 추정에만 적용하며, 번호를 생략하거나 문자열을 고쳐서 통과시키지 않는다.

## 표지 자동 검출은 미해결

800×1125 표지의 추가 로그는 v0.3.7 `compact_context`가 실제로 실행되어도 같은 글자 조각을
완전하게 재검출하지 못했음을 보여준다. 따라서 compact 창 추가를 이 표지의 해결로 간주하지 않는다.
임계값을 올려 조각을 버리거나 실패한 조각을 완전 검출인 것처럼 통과시키지 않는다.
현재 모델의 자동 경로에서는 계속 명확한 오류로 중단한다. 추가 자동 검출 보완에는 실제 모델의
다른 검출 방법/입력에 대한 성공 근거가 필요하다.

## 09 수동 영역 통합

[09 GUI JSON](../lettering/example_workflows/09-manual-regions-integrated-cleanup-lettering.json)을 새로 불러온다.
`.api.json`은 API 제출용이다. 원본 이미지를 선택하고 두 번째 `MangaRegionCrops`의 `layout_json`을
확인한다. 이 경로에는 RF-DETR 로더/검출/경계 복구가 없고 새 커스텀 노드도 없다.
지정 프레임 → Hayai → 원문 JSON/미리보기 → 번역 → 번역 JSON/미리보기 → 타일 제거 → 식자 → 저장으로 연결된다.

기본 JSON은 보고된 표지용 사람이 지정한 세 프레임이다. 좌표는 가로/세로 각각 0..1000의 xyxy다.

| ID | 정규화 bbox | 식자 방향 |
| --- | --- | --- |
| location | `[858,24,954,61]` | 가로 |
| booth | `[423,57,970,170]` | 가로 |
| title | `[44,300,284,970]` | 세로 |

각 입력의 문자열을 미리 쓰거나 정답으로 주입하지 않는다. 다른 이미지에서는 이 좌표를 그대로
쓰지 말고 `layout_json`과 식자 계획의 ID별 방향을 수정한다. 원문 JSON에는 `origin=manual`이 남는다.
하나의 영역 JSON/manifest가 OCR과 제거/식자에 함께 사용되므로 여러 노드의 좌표를 따로 맞출 필요가 없다.

**이 경로의 기본 마스크는 사각형 전체이며 글자 획 segmentation이 아니다.** `edit_margin=0`,
GrowMask 확대 0이지만 지정 사각형 안의 그림도 Qwen이 재생성할 수 있다. 마스크와 식자 직전 배경
미리보기를 확인한다. 정밀한 마스크를 직접 준비했다면 source_mask와 GrowMask 입력을 교체할 수 있다.
08의 연결/기본 설정은 변경하지 않는다. 제거 결과는 `manga_translator/manual_tiles` 접두사로 저장한다.

전체 09 그래프는 합성 입력과 모델 응답 대역으로 검증한다. 이것은 실제 표지의 Hayai/Qwen/번역/식자
성공 검증과 구분한다. 수동 프레임 우회는 자동 검출 개선이 아니다.

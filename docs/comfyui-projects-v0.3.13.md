# ComfyUI 안에서 폴더 프로젝트 처리

v0.3.13부터 기본 사용 흐름은 **ComfyUI 캔버스의 08 설정 → 왼쪽 ‘만화 번역 프로젝트’ → 폴더 실행**이다. 터미널 실행이나 API JSON 내보내기는 필요 없다. 일반 이미지 한 장은 기존처럼 08의 실행 버튼을 사용한다.

## 사용 순서

1. 업데이트 후 ComfyUI를 재시작하고 브라우저를 새로고침한다.
2. `lettering/example_workflows/08-integrated-tiled-cleanup-lettering.json`을 열고 모델·번역 서버·언어·식자 설정을 맞춘다. OCR/번역 저장 뒤의 기본 ‘미리보기 아무거나’ 연결도 유지한다.
3. 왼쪽 책 아이콘의 **만화 번역 프로젝트** 탭을 연다.
4. 프로젝트 이름을 입력하고 원본 폴더를 선택한다. **내 PC 폴더 업로드**는 Windows 폴더와 하위 이미지들을 ComfyUI 서버에 전송한다. 프로젝트 원본을 모은 하위 폴더를 선택한다. 내부 작업 이미지까지 재입력되는 것을 막기 위해 `input` 전체와 내부 `manga_translator` 작업 폴더는 실행하지 않는다. 이미 DGX 서버의 `ComfyUI/input` 안에 있다면 **서버 input 폴더 선택**으로 찾아 선택한다.
5. **현재 08 설정으로 새 프로젝트 시작**을 누른다. 지금 열려 있는 캔버스 설정을 저장하고 한 페이지씩 기존 ComfyUI 큐에 제출한다. 다른 종류의 그래프나 저장/입력 노드가 여러 개인 그래프는 설정 오류로 알려 준다.
6. 패널에서 페이지별 진행 상태·실패 원인·결과 이미지·OCR JSON·번역 JSON을 확인한다. 파일명 숫자 순으로 정렬하며 같은 이름의 하위 폴더 이미지도 구분한다.

## 중지·재개와 설정 변경

- **일시정지**는 현재 페이지를 마친 뒤 다음 페이지 제출을 멈춘다. 다른 ComfyUI 작업을 강제로 취소하지 않는다.
- **저장된 설정으로 재개**는 프로젝트를 만들 때 저장한 08을 사용한다. 완료 결과를 검증하고 건너뛰며, 접수 중이던 작업은 기존 작업 ID부터 확인한다.
- **실패 페이지도 한 번씩 다시 시도**를 선택하면 이미 실패한 페이지에 새 시도를 하나씩 추가한다. 이전 기록은 남는다. ‘검토 필요’는 실패 재시도 대상과 다르다.
- 캔버스에서 모델이나 언어·식자 설정을 바꿔 새 실행을 원하면 **새 프로젝트**를 만든다. 기존 프로젝트의 설정을 몰래 바꾸지 않는다.
- 브라우저를 닫아도 서버에서 처리가 계속된다. 서버 자체가 중단되면 재개 시 작업을 다시 확인한다. ComfyUI 큐/히스토리에도 작업이 남아 있지 않아 접수 여부를 알 수 없으면 무작정 다시 제출하지 않고 일시정지한다.
- 동시에 실행하는 폴더 프로젝트는 하나다. 일반 ComfyUI 작업은 기존 큐 규칙을 따른다.

## 결과와 예외 처리

패널에 정확한 저장 위치를 표시한다. 프로젝트 기록은 `ComfyUI/output/manga_translator/folder_projects/<프로젝트 ID>/`에 있으며, 페이지마다 원본 정규화 PNG·결과 PNG·원문/번역 JSON·시도 기록을 보존한다. 완료한 결과의 정렬된 복사본은 `exports/<판 ID>/000001.png` 형식으로 만든다. 실패·검토 페이지의 번호는 비워 두고 `index.json`에 남기므로 빠진 페이지를 성공 결과처럼 취급하지 않는다.

| 상황 | 처리 |
| --- | --- |
| 일반 페이지의 검출 경계/OCR/식자 실패, 손상 이미지 | 해당 페이지 실패를 기록하고 다음 페이지 진행 |
| 균일한 빈 이미지이고 선택 검출도 없음 | 원본과 같은 결과를 확인한 뒤 빈 페이지로 기록 |
| 단색이 아닌데 검출 없음, 제외된 효과음 존재 | 원본을 보존하고 검토 필요로 표시 |
| 메모리·디스크·모델 구성 오류, 접수 응답 유실 | 추가 제출을 멈추고 일시정지 |
| 결과 파일이 삭제되거나 수정됨 | 기존 작업에서 복구하거나 검토 상태로 보존 |
| 업로드 도중 실패 | 자동으로 실행하지 않음. 모든 파일 전송이 끝나야 새 입력 폴더가 선택됨 |
| 입력 파일이 바뀜/추가됨/삭제됨 | 기존 이력과 작업 ID를 보존하고 다음 재개에서 다시 비교 |

하위 폴더를 포함한다. 이미지 형식은 PNG/JPEG/WebP/BMP/TIFF/GIF이며 다중 프레임·16비트 입력은 명시적 변환이 필요해 페이지 실패로 기록한다. 현재 08과 동일하게 페이지당 최대 16,777,216픽셀이다. 투명 배경은 흰색에 합성하고 EXIF 방향을 적용한다. 원본 파일은 수정하지 않는다.

## 검증과 남은 제한

ComfyUI 프런트엔드 1.53.10과 실제 확장/HTTP 경로에서 패널을 검증한다. 검출·Hayai·번역·Qwen 응답은 테스트 대역이며 DGX의 실제 GPU 품질 실증은 별도다. 완료는 실행과 결과 파일 검사가 끝났다는 뜻이다.

일부 표지의 자동 검출 실패, 본문 안의 숫자 영역 구분, 혼합 제목·문단의 의미상 구분, OCR의 의미 오류는 여전히 개선 대상이다. 폴더 기능이 이를 해결한 것으로 간주하지 않는다. 번역은 현재 페이지 단위이며 책 전체 용어집/문맥 공유는 아직 없다. 예전 CLI는 자동화용 보조 도구로 남기고, 일상 사용은 이 ComfyUI 패널을 기준으로 한다.

# 종이 질감에 의한 누락 검사 오탐 — v0.3.8

실제 제공된 실패 입력은 280×51 크기의 짧은 중국어 문장과 종이 질감이다.
원본 영역 280×428의 `line=5` 입력이며, 이전 580×203 다단 반복 사례와 다른 실패다.
진단에는 첫 patch 시도 8자, 다음 시도 7자, 최종 `possible_omission`이 기록되어 있다.

기존 검사는 모든 전경 픽셀의 세로 투영 띠를 셌다. 이 입력에서는 작은 종이 잡음까지 38개 띠로
계산되어 최소 10자를 요구했고, 7/8자 문장을 누락으로 판정했다. 이는 검사의 오탐이다.
다만 최종 저장 문자열에는 실제 글자 오인식도 있으므로 오류가 사라지는 것과 정확한 OCR은 구분한다.

이제 누락 추정에만 8방향 연결 성분의 면적 4픽셀 미만을 제외한다. 실제 입력의 유효 띠는 12개,
약한 문자 수 하한은 3자가 되어 7/8자 결과를 거부하지 않는다. 이 하한은 실제 글자 수 추정이나
OCR 신뢰도가 아니다. 큰 잡음이나 연결된 글씨를 완전히 구분하지 못하는 휴리스틱이다.

인식 입력, 전경 마스크, OCR 분할, 반환 문자열을 이 검사에서 수정하지 않는다. 불필요한 누락
재시도를 하지 않아 첫 출력을 다른 patch 출력으로 덮어쓰는 경로도 피한다. 보고서의 각 품질
시도 `quality_evidence.omission`에는 원래 띠 수, 성분 근거가 있는 띠 수, 분석 면적 기준과 하한을
남긴다. 짧은 반복/빈 출력/토큰 한도 검사는 유지하고, 충분한 글자 근거가 있는 실제 누락 경보도 유지한다.

실제 실패 이미지 픽셀로 기존/변경 판정을 재현했다. 공개 테스트는 첨부 파일 대신 별도로 그린
종이 잡음/짧은 문장 구조를 사용한다. 밝은 글씨와 어두운 글씨, 작은 실제 글자들의 누락 경보,
반복 거부, 불필요한 재시도 없이 첫 결과 유지와 진단 값을 검사한다.
실제 Hayai의 첫 8자 문자열은 진단에 없으므로 그 출력이 정확했다고 판단하지 않는다.
이 환경에서 사용자 GPU의 실제 Hayai 정확도는 검사하지 않았다.

코드를 업데이트하고 ComfyUI를 재시작한다. 기존 08 옵션/연결과 `quality_guard=true`를 유지한다.

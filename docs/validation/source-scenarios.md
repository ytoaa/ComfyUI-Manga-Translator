# v0.7.15 원문 소유권 시나리오

실행 보고서에서 전체 원문과 그 일부가 같은 text로 남아 별도로 OCR·식자된 것을 확인했습니다. 경계 판정을 무조건 무시하지 않고 실제 마스크의 양성 획 포함 근거로 중복을 해소합니다. 마스크가 없거나 서로 다른 획이면 새 우회 근거를 만들지 않습니다. 같은 분류의 모호한 공유 획은 bubble_verified보다 먼저 검수하며 연결 원문 보호가 전파됩니다.

## 합성 입력

Pillow와 번들 폰트로 재현 가능한 원문 픽셀을 만들고, 검출 관측과 번역문은 고정한 대역을 사용합니다. 흰색/회색 배경의 포함 중복, 축을 바꾼 포함 중복, 혼합 대사 크롭, 독립 대사, 완전 중복, 문장 끝을 놓친 부분 중복, 투영이 합쳐진 다중 글자 등 8개 시나리오입니다. 사용자 원본·대사·마스크는 공개하지 않습니다.

검출 정리→편집 허가 계획→알려진 배경을 이용한 제거 대역→실제 CPU 식자·합성으로 연결합니다. 각 시나리오에 source.png/result.png/regions.png와 진단 JSON을 생성합니다(크기 추정 보존 사례는 source/result와 JSON). 90도 회전 원문은 측정 불일치로 원본을 보존하는 조건까지 확인합니다. 편집 범위 밖 픽셀 불변, 완전한 원문 프레임 유지, 중복 번역 방지, 혼합 영역 원본 보존을 검사합니다. 흐린 이미지·실제 검출 정확도·OCR·번역·Qwen 제거를 실행한 시험은 아닙니다.

```bash
PYTHONPATH=/path/to/test/dependencies python tools/simulate_source_scenarios.py --destination /tmp/source-scenarios
python -m pytest tests/test_page_scenarios_v0715.py --rootdir=tests --confcutdir=tests
```

## 검수와 한계

- 크기 추정 불일치는 충분한 작은 연결 성분이 있는 큰 투영 덩어리를 찾는 휴리스틱입니다. 정상 큰 글자 전체를 축소하지 않습니다. preserve_review는 원본 보존, stop/strict는 중단이며 명시적 font_cap은 검수자가 크기를 정하는 경로입니다.
- readable에서 원문 비율을 완화한 출력은 원본 보존 항목과 별개로 경고하고 needs_review로 표시합니다. 절대 최소 크기를 낮추지 않습니다.
- OCR의 짧은 오독, 부정어 누락, 번역의 불필요한 설명, 모든 잘린 문장을 문자열만으로 판별하지 않습니다. 잘못 겹친 크롭이 정리되면 그 원인의 중복·잘린 입력은 줄지만 인식 정확도 보증은 아닙니다.
- 원시 마스크가 없는 첨부 보고서만으로 해당 페이지의 동일 추론을 재생하지 못했습니다. 운영 ComfyUI/GPU·실제 브라우저와 Actions 결과도 별도입니다.

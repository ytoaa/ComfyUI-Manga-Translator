# 검출 후보 예산

[검증 목차](README.md) · [설정](../configuration.md)

v0.7.10은 전체·상세 타일에서 같은 원문을 반복 관측한 후보가 상세 검출의 512개 예산을 불필요하게 소모하는 경우를 보완합니다. 예산에 여유가 있을 때는 기존 후보를 그대로 유지합니다.

통합 조건은 같은 분류, 동일한 원본 좌표의 사각형, 비어 있지 않은 마스크, 작은 획의 98% 이상 및 큰 획의 70% 이상 겹침입니다. 둘 모두 타일 경계에서 잘리지 않은 완전한 후보여야 합니다. 좌표만 겹치거나 문장이 같다는 이유로 합치지 않습니다. 마스크는 합집합을 사용하며 기존 출처를 `source_provenance`에 보존합니다. 잘린 조각은 경계 복구의 끝점 근거이므로 그대로 남깁니다.

`detail_detection.candidate_budget`의 `raw_candidates`, `retained_candidates`, `consolidated_sources`, `limit`로 상세 탐지까지의 관측 수와 보관 수를 구별합니다. 복구 호출에서 추가된 후보는 이 상세 탐지 통계와 구별합니다. 통합 뒤에도 독립 후보가 512개를 넘으면 기존 오류를 유지합니다.

후속 JSON의 논리 영역 128개와 식자 64개 한도는 유지합니다. 촘촘한 다단 설명문은 검출 한도를 통과해도 논리 영역 한도에서 중단될 수 있습니다. 왼쪽 정렬과 간격이 맞는 가로 본문에는 기존 `merge_adjacent_lines=True`를 선택해 문단 묶음을 검수할 수 있습니다. 이 옵션을 모든 만화에 자동 적용하지 않습니다. 단·말풍선·컷이 잘못 합쳐지지 않는지 확인해야 합니다.

새 회귀는 마스크 합집합·출처 보존, 다른 좌표·분류·획의 분리, 잘린 조각 보존, 마스크 없는 후보 분리, 중복 통합 후 한도 유지와 독립 후보의 한도 초과 거부를 검사합니다. 실제 모델의 인식 정확도나 페이지 완성률과는 별개입니다. 사용자 원본·마스크·실행 결과는 저장소에 넣지 않습니다.

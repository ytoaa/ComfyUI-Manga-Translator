# v0.7.16 실제 결과 재점검

v0.7.15의 합성 이미지 시험은 검출 관측과 번역문을 고정했으므로 모델이 만든 새로운 줄바꿈 표기를 잡는 검증이 아니었습니다. 924개 회귀 통과를 실제 페이지의 번역 완성도와 혼동하지 않습니다.

이번 실제 실행은 검출 23개이며 식자 결과는 18개입니다. source_preservation은 원문 3개와 미할당 획 1개이고 lettering_review는 크기 추정 실패 1개와 그에 겹친 이웃 1개입니다. r13/r14는 ambiguous_source_overlap, r12는 보호 전파, r21은 321px 크기 추정 불일치, r18은 그 원문 복원 범위와 겹쳐 보존됐습니다. 이들은 삭제 실패가 아니라 자동 편집을 완료하지 못한 상태입니다.

## 실제 문자열 검사

첨부 OCR과 최종 식자 보고서를 영역 ID로 대조했습니다. r3/r5/r8/r11의 문구 사이 표기는 U+006E 일반 영문 n입니다. 기존 translation_text는 이 네 실제 문자열을 모두 허용했습니다. 새 검사는 네 건을 모두 거부하며 모델 응답의 기존 한 번 재요청을 사용합니다. 재차 실패하면 결과 전체를 반환하지 않고 진단을 남깁니다. 정상 영문, 원문에 독립 n이 있는 변수 표현, 수동 교정과 실제 줄바꿈을 보존하는 별도 회귀를 추가했습니다.

이 검사는 의심 표기를 찾는 좁은 휴리스틱입니다. 대문자 N이나 모든 다른 표기를 포괄하지 않으며 자동으로 문장을 고치지 않습니다. 원문 자체에 n이 있으면 번역자가 추가한 것인지 알 수 없어 이 검사를 적용하지 않습니다. n 검사는 모델 응답에만 적용하며 이미 작성한 수동 번역을 재해석하지 않습니다.

## 미해결 사항

- 보호된 원문 영역을 다시 독립된 완전한 대사로 복구하는 문제는 남아 있습니다. 보존 정책이 작동했다고 자동 번역이 완료된 것은 아닙니다.
- 제공된 보고서에는 실제 검출 RLE 마스크가 없어 획의 공유·잘림과 고유 획 분리를 같은 입력으로 재생하지 못했습니다. 결과 스크린샷도 원본 2150×3035 페이지 픽셀을 대체하지 못합니다.
- OCR 오독·부정어 누락·표현과 불필요한 해설의 번역 품질, 실제 모델 재요청 성공률, 운영 GPU/ComfyUI/브라우저는 이번 수정의 검증 범위가 아닙니다.

## 실행 기록

전체 CPU 회귀 937 PASS (124.23초), 새 전용 회귀 13개와 관련 검사 82개를 통과했습니다. 별도로 실제 첨부의 네 문자열을 기존/새 검사에 각각 넣어 기존 허용·새 거부를 확인했습니다. 후자는 합성 예문 시험과 구분하며 사용자 대사를 공개 저장소에 저장하지 않았습니다. 컴파일, JS 노드 UI·캔버스 계약, 워크플로 생성기 일치, 등록 파일 182개/로컬 링크 114개, 실행 ZIP 95개/소스 ZIP 183개 파일 무결성을 확인했습니다. 실제 번역 서버의 재요청 성공과 원문 보존 영역 복구를 검증한 수치는 아닙니다.

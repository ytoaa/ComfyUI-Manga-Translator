# v0.7.13 식자 실패 경로와 저장소 검토

검토일: 2026-10-26 KST. 운영 로그의 `r1: source size 6px is below readability minimum 10px`를 출발점으로 식자 계획·렌더링, 검출 마스크, 번역 응답, 편집 소유권, 캐시·폴더 수집, UI·패키징·CI 경계를 검토했습니다. 첨부 화면의 같은 전체 페이지·검출 마스크·번역 JSON은 없어 운영 입력의 완전 재생으로 표현하지 않습니다.

## 확인·수정한 결함

| 경로 | 이전 문제 | 수정 후 동작 |
| --- | --- | --- |
| 원문 상한보다 큰 최소 크기 | 계획 단계에서 항상 페이지 중단 | preserve_review는 부모 편집 범위를 복원·검수, 독립 영역은 계속 처리. stop/strict는 중단 |
| 회전 보정 후 측정 | 두 번째 스타일 측정만 보존 처리에서 빠짐 | 확인된 획 부족만 동일한 보존 경로에 연결. 잘못된 좌표·각도·예산은 계속 오류 |
| 전체 부모 편집 범위 | 이웃의 자식 사각형만 겹침 검사 | 실제 원본 복원 범위로 보존 전파. 명시적 strict 이웃은 중단 |
| 정상 비한글 폰트 | 번역 지원 여부와 별개로 한글 '가'를 측정에 요구 | 한글이 있으면 기존 기준 유지, 없으면 실제 지원 글리프로 측정 |
| bubble 확장 | respect_bubbles=false에서 구형 전역 후보 검사에 재진입 가능 | 확장도 같은 관련 후보/실제 획 소유권 검사를 사용. 마스크 합집합으로 권한을 넓히지 않음 |
| 글자 획 침식 | 유효한 음수 weight로 글자가 사라지면 일반 예외로 중단 | 배치 실패로 취급해 bounded 탐색 후 보존 또는 stop/strict 오류 |
| 잘못된 조판 설정 | 원문 품질 실패가 설정 오류보다 먼저 처리될 수 있음 | 방향·모드·최소 크기·회전·간격·Boolean·layout 키를 먼저 검사 |
| 검수 보고서 | 크기 충돌 수치가 없고 일반 보존도 말풍선 skip_reason 사용 | 크기/최소 크기·추정/override 출처 기록, 일반 식자 보존 상태 구분 |
| CI | 대체 모델 전처리 회귀에 필요한 OpenCV 설치 누락 | CPU 검증 의존성에 opencv-python-headless 추가, pytest rootdir을 tests로 고정 |

최소 크기나 원문 상한을 자동 완화하지 않습니다. `region_options_json={"r1":{"font_cap":10}}`은 사람이 확인해 확대를 허용하는 별도 선택입니다. 작은 원문이 실제로 글자인지, 검출 마스크가 완전한지는 이번 규칙으로 인증하지 않습니다.

## 검증 방법

최종 CPU 회귀는 **899 PASS (172.07초)**입니다. 노드 UI·캔버스 JS 계약 PASS, 통합 워크플로 생성기와 저장 JSON 일치, Python 컴파일 PASS, 등록 파일 174개·문서 링크 108개·어댑터 출처 검사를 통과했습니다. 실행 ZIP 91파일과 source ZIP 175파일의 ZIP·개별 파일 SHA256 검사를 통과했습니다. 실제 Chromium 검사는 실행 파일이 없어 시작하지 못했으며 PASS로 세지 않습니다.

새 전용 회귀 26개는 실제 동봉 폰트로 만든 6px 추정 입력, 원본 픽셀과 양의 글자 알파 보존, 독립 영역의 완전한 번역문, 부모 범위 전파, strict 이웃·stop·명시적 확대, 잘못된 옵션, Latin 전용 subset 폰트, 전역 64개를 넘는 말풍선 관측, 실제 획 침식의 실패 경로를 검사합니다. 회전 후 획 부족은 측정 실패를 주입한 계약 검사로 구분합니다. 사용자 이미지는 회귀나 공개 저장소에 포함하지 않습니다.

기존 검출/마스크·OCR·번역·편집 소유권·캐시 세대·프로젝트 재개·픽셀 보호·패키징 회귀를 모두 실행합니다. 잘못된 RLE, 없는 폰트, 글리프 누락, 잘못된 설정, 자원 한도 위반을 전부 같은 예외로 삼키는 방식은 사용하지 않습니다. 노드 UI와 캔버스 JS 계약, 통합 08 생성기 동등성, Python 컴파일, 등록 파일·문서 링크·어댑터 출처, 실행용/source ZIP 검사를 함께 수행합니다.

## 별도 검증이 필요한 범위

CPU 회귀와 정답을 통제한 폰트/픽셀 검사는 모델의 OCR·번역 정확도나 생성 배경 품질을 보증하지 않습니다. 실제 DGX/ComfyUI GPU 실행·사용자 브라우저 화면·GitHub Actions 실행은 이번 로컬 검증과 별개입니다. 폰트의 실제 글리프 지원 확인도 Arabic 등 모든 언어의 연결 조형·양방향 조판 지원을 뜻하지 않습니다. 원문이 남은 첨부 영역의 최초 보존 원인은 해당 실행의 OCR/번역 JSON과 식자 보고서로 대조해야 합니다.

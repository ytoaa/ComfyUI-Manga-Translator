# 추가 이미지·처리 경계 검사

사용자 원본 9장 검사 뒤, 예상 가능한 다른 입력을 새 글자·도형으로 만들었습니다. 생성 페이지 **15종**, 실제 OCR용 대표 크롭 **17종**, 처리 조건 **77개**입니다. 사용자 이미지·검출 결과·모델 답변으로 정답을 만들지 않습니다. v0.7.7에서 실제 검출로 드러난 동일 획의 분류 중복을 수정하며, 추가 검증과 남은 모델 품질 한계를 구분합니다.

## 새 이미지

| 유형 | 확인할 위험 |
| --- | --- |
| 10/14/20px 말풍선 글씨 | 작은 원문이 최소 식자 크기 정책과 충돌 |
| 가로·세로·Latin 혼합 | 입력 방향·단어·문자 누락 |
| 검은 바탕의 흰 글씨·유색 배경 | 명암 극성·색 추정·실제 OCR |
| 저대비 글씨 | 검출되더라도 OCR·스타일 추정 실패 |
| 테두리 효과음 | 포함 스위치·회전·윤곽·미검출 |
| 숫자·문장부호 혼합 | 영문·숫자·구두점의 보존과 세로 식자 |
| 2400×1800 고해상도 | 상세 창·경계 복구·좌표·리소스 제한 |
| 그라데이션 자막·스크린톤 | 단색 채우기로 그림을 지우지 않는지 |
| -23/12/24도 글씨 | 기울어진 입력의 검출·인식·명시적 회전 식자 |
| 좁고 긴 세로 글줄 | 방향별 줄바꿈과 최소 크기 |
| 겹치는 문단 프레임 | 원문 공간 예약·완전한 문자열·알파 충돌 |
| 작은 주석 12개 | 개수만으로 놓친 글줄을 숨기지 않는지 |
| 페이지 밖에서 잘린 글자 | 보이지 않는 정답을 복구했다고 부르지 않기 |
| 글자 없는 도형·선 | 그림의 오검출과 무처리 원본 보존 |

폰트 문자 지원을 검사하며 원본·지운 배경·글자별 알파를 독립 저장합니다. 정답 배경은 글자를 그리기 전에 존재합니다. 글자 알파 밖의 원본과 정답 배경이 같아야 하므로 그림을 잘못 덮어쓴 생성기 자체도 회귀에서 잡습니다.

## 검사 구분

- **제거 15조건:** 생성기의 정확한 원문 마스크·영역을 입력으로 실제 편집 계획·단색 제거·합성을 실행합니다. 실제 검출 성공을 뜻하지 않습니다. 정답 배경은 채점에만 사용합니다. 그라데이션·스크린톤 등은 Qwen 출력이 없으면 완료로 세지 않습니다. 원문 잔존, 그림 오염, 제거 마스크 밖 픽셀을 따로 검사합니다.
- **식자 45조건:** 가로 기본/1.6배 길이·세로 기본 길이입니다. 이 단계만 분리하기 위해 생성기의 정확한 지운 배경을 명시적으로 입력합니다. Qwen이 지운 결과로 위장하지 않습니다. 완전한 시험 문자열·양의 글자 알파 비충돌·보호 픽셀·합성 밖 픽셀을 검사합니다. 잘린 원문 보존과 빈 입력의 식자 0개를 번역 성공으로 세지 않습니다.
- **과다 길이 1조건:** 유효한 길이의 지나치게 긴 문장을 조판 거부하는지 봅니다. 폰트 누락 등 다른 오류로는 통과하지 않습니다.
- **파일 입력 7조건:** RGBA/팔레트 투명도·EXIF의 실제 정규화 픽셀, 고비트 이미지·다중 프레임·손상 파일·검사 뒤 바뀐 입력 거부입니다.
- **생성 결과 주입 9조건:** 정답·그대로인 원문·절반 남은 원문·틀린 배경색·누락/추가 타일·잘못된 크기·NaN·소유 영역 밖 오염입니다. 명시적 결과 대역이며 실제 Qwen 품질 측정이 아닙니다. 잘못된 결과가 실행 계약을 통과해도 독립 정답과 다르면 GAP입니다.
- **실제 RF-DETR / Hayai:** 고정 SHA 번들을 CPU에서 실행합니다. 검출은 실제 영역 정리·마스크·크롭까지 독립 글자 알파 포함률·중복 입력·빈 그림 오검출을 평가합니다. 효과음 포함 설정을 명시합니다. OCR은 정답을 알고 만든 대표 크롭을 읽으므로 해당 위치를 검출기가 찾았다는 뜻은 아닙니다. 잘린 입력은 완전한 문장의 OCR 정답에서 제외합니다.

PASS/GAP/ERROR와 미완료 실행은 기존 [페이지 시뮬레이션](image-scenarios.md)의 뜻을 따릅니다. 의도된 중단·보존·모델 호출 요구도 개별 계약의 PASS가 될 수 있습니다. 전체 이미지 성공 수가 아닙니다.

## 실행

개발 source ZIP 또는 Git 체크아웃과 기존 CPU 개발 환경을 사용합니다. 운영 torch/CUDA를 교체하지 않습니다. 모델 번들은 [CPU 검사](cpu-models.md)의 고정 파일입니다.

```bash
python tools/stress_image_processing.py --mode generate --destination ../expanded-results
python tools/stress_image_processing.py --mode contracts --destination ../expanded-results
python tools/stress_image_processing.py --mode detector --include-sfx --models /path/to/models --destination ../expanded-results
python tools/stress_image_processing.py --mode ocr --models /path/to/models --destination ../expanded-results
```

종료 코드는 0=미충족 없음, 1=GAP 있음, 2=예기치 않은 실행 오류입니다. 알려진 GAP도 성공으로 바꾸지 않습니다. 결과는 저장소 밖에 저장하며 입력·정답·실제 원출력·모델 revision·소스 SHA를 남깁니다. 새 입력은 재현 가능한 생성 코드만 커밋합니다.

## v0.7.7 수정과 재검증

테두리 효과음에서 같은 획이 일반 텍스트와 효과음으로 중복 분류됐습니다. 검증된 좌표와 양의 분할 마스크가 모두 같은 두 후보만 최고 점수 하나로 합칩니다. 다른 좌표·다른 마스크·마스크 없는 후보는 유지하며, 식자 충돌 거부 기준은 낮추지 않습니다. 효과음 제외 선택도 유지합니다. 단계 캐시/처리 버전을 올려 이전 중복 영역 캐시를 재사용하지 않습니다.

수정 전 실제 RF-DETR는 15종에서 **12 PASS / 3 GAP**이었고, 수정 후 같은 입력·고정 가중치로 CPU 추론부터 다시 실행해 **13 PASS / 2 GAP / ERROR 0**입니다. 동일 효과음의 OCR 크롭은 2→1개, 중복 획 비율은 1.0→0입니다. 남은 2개는 기울어진 글씨의 불확실 기하 보존과 비문자 평행선의 오검출입니다. PASS는 정의한 획 포함/중복/비문자 대조 기준에 한정되며 일반 검출 정확도가 아닙니다.

비문자 오검출의 실제 크롭을 실제 Hayai와 OCR 수집 노드까지 이어 실행하면 모델 호출 1회로 `IIIIIII`를 채택했습니다. quality_guard/preserve_review가 모든 환각을 거부하지 못합니다. 제거 후 그림 손상까지 실행한 결과는 아니며, 비문자 오검출을 안전하게 처리했다고 세지 않습니다.

수정 후 제거/식자 등 77조건, 실제 검출 15종, 실제 OCR 17크롭의 세 모드는 동일 운영·검사 소스 SHA로 완료됐습니다. 전체 CPU 회귀는 **767 PASS**이며 중복 병합·분리 유지와 추가 생성기/채점 음성 대조 회귀 12개를 포함합니다. 통합 그래프 모의 실행, JS UI 계약, GUI/API 생성 일치, 소스/패키지 무결성은 모델 품질과 구분합니다.

## 관측 해석

77개 처리 조건에서 **69 PASS / 8 GAP / ERROR 0**입니다. 미충족은 작은 글씨 3방향/길이 조건, 저대비 3조건, 잘못된 생성 결과 수용 2조건입니다. **4가지 상황을 여러 조건으로 검사한 것**이며 8개 독립 결함이나 일반 실패율이 아닙니다.

작은 글씨는 추정 원문 크기가 9px라 최소 10px 정책에서 중단했습니다. 저대비는 스타일 추정의 변경 픽셀 근거가 부족해 중단했습니다. 두 경우를 잘린 식자의 성공으로 세지 않습니다. 이는 기본 정책의 제한이며 그 자체로 코드 결함 판정은 아닙니다.

원문 절반이 남거나 배경색이 틀려도 현행 합성 검사가 받아들인 주입 조건이 있습니다. 현재 검사는 원문이 거의 그대로인 타일을 찾는 휴리스틱이며, 원문 완전 제거·복원 배경 정확도를 인증하지 못합니다. 검사 기준을 임의로 낮추거나 생성 답변을 정답으로 사용하지 않았습니다.

실제 Hayai 대표 크롭은 **4개 정확 일치 / 13개 미일치**입니다. 미일치 중 2개는 공백 차이만 있고, 나머지는 철자 차이가 있습니다. 저대비에서 무관한 글자, 작은 일본어·혼합 문자·흰 글씨·스크린톤에서 오독이 관측됐습니다. 이 17개 인쇄체 입력의 결과를 일반 OCR 정확도로 확대하지 않습니다. 실제 검출 결과는 별도 실행 JSON과 전달 보고서에서 확인합니다.

실제 번역 생성은 제외했습니다. 실제 Qwen 배경 생성, 네이티브 ComfyUI 실행기, GPU 동등성은 이 추가 검사에서도 미검증입니다. 생성한 정답 배경을 쓰는 식자 검사나 타일 주입을 실제 전체 처리 완료로 표현하지 않습니다.

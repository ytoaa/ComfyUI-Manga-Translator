# 원문 소유권과 부분 보존

v0.7.9는 검출 후보가 실제 글자인지, 원문을 모두 찾았는지 보증하지 않습니다. 같은 원문을
두 번 처리하는 경로와 불확실한 원문을 지운 채 식자에 실패하는 경로를 먼저 보완합니다.

## 원문 중복과 문단 경계

교차 분류 중복은 원본 bbox가 완전히 같고, 마스크의 작은 쪽 포함률이 92% 이상이며 큰 쪽
포함률도 70% 이상일 때만 통합합니다. 이는 이 버전의 보수적 휴리스틱이며 동일 의미나
문자 정답의 증명이 아닙니다. 마스크 IoU만으로 결정하지 않습니다. 별도 획인 자막·효과음,
마스크가 없는 후보, 다른 위치에서 반복되는 대사와 다른 원본 프레임은 별도로 남깁니다.

다른 원본 프레임이지만 상당한 획을 공유하는 교차 분류는 자동 통합하지 않고 관련 ID를
검수로 표시합니다. 기본 편집 정책에서는 원본 보존하며 확인 후 명시적으로 교체할 수 있습니다.

`source_ownership`에 원래 검출 ID·분류·교차 분류 통합 여부와 말풍선 획 포함 근거를
저장합니다. 픽셀 제거 마스크는 실제 원본 검출 마스크들의 합집합 경로를 계속 사용합니다.
한 영역을 통합했다고 소수 후보의 획을 삭제 마스크에서 버리지 않습니다.

문단 묶기는 같은 말풍선·컷 소유권, 행 높이·간격·정렬을 확인합니다. 중첩된 페이지/컷은
가장 안쪽의 일관된 컷을 사용하고, 겹친 컷 소유권이 모호하면 합치지 않습니다. 검출기가
컷이나 말풍선을 찾지 못했다면 없는 구조를 추정해 인증하지 않습니다.

반복 검출된 거의 같은 말풍선 마스크는 공통 내부로 축소해 정리합니다. 임의의 합집합으로
안전 범위를 넓히지 않습니다. 서로 다른 말풍선 64개 한도와 픽셀 예산은 유지합니다.

## 삭제 전 검수

`source_review_policy=conservative`는 새 검출 소유권 명세가 있는 영역에서 검증된 말풍선
밖 한 글자 후보와 큰 표지형 원문을 보존합니다. 여러 가로 글줄로 확인한 문단은 큰 제목
검수 규칙에서 제외합니다. 실제 한 글자 대사도 검수로 갈 수 있습니다. 이는 리본 등의
그림 오탐을 확정 판별하는 모델이 아니며 일반 오탐 방지 정확도를 인증하지 않습니다.

확인한 ID에 `region_actions_json={"r1":"replace"}`를 지정하면 문자성 검수를 해제할 수
있습니다. 보호 원문과의 교차는 계속 막습니다. 수동 문서는 기존 권한 의미를 유지하며
`legacy`는 기존 교체 정책입니다. 동일 편집 프레임의 별개 후보는 삭제 전 공간 검수로
보존하며, 보호와 연결된 이웃도 먼저 닫아 일부 원문만 지워지는 것을 방지합니다.

## 식자 실패 복원

`fit_failure_policy=preserve_review`는 실제 최소 크기에서도 배치가 불가능할 때 해당 원문과
겹쳐 연결된 편집 프레임을 원본으로 복원합니다. 문단 자식이 실패하면 부모 편집 프레임을
보존합니다. 이전 배치 시도는 버리고 보호를 반영해 독립 영역을 다시 맞춥니다. 실제 알파
검사가 전체 통과한 뒤 처음 합성하므로 실패한 시도의 글자 레이어는 최종 출력에 남지 않습니다.

원본/배경 차이로 스타일을 측정할 수 없는 영역도 검수 경로에서 보존합니다. 폰트 누락,
변조된 명세, 리소스 한도, 모델 실행 오류는 검수 성공으로 바꾸지 않습니다. `strict`와
`stop`은 계속 명시적으로 중단합니다.

스타일 분석은 실제 지운 배경을 참조합니다. 삭제 전 원문/공간 검수와 제거 후 실제 글자
배치 검사는 별개입니다. 제거 모델 계산 자체를 모두 생략하는 완전한 사전 식자 검사는 아닙니다.
반투명 배경이나 그림 속 제목을 원래대로 복원한다는 보증도 아닙니다.

## 검사와 해석

독립 합성 회귀는 같은 프레임의 다른 획, 작은 자막/큰 효과음, 이동한 반복 대사, 서로
다른/중첩/겹친 컷, 실제 한 글자 대사의 확인 경로, 보호 전파, 명세 변조, strict 유지,
실패 그룹 원본 복원과 독립 식자를 검사합니다. 공개 테스트에 사용자 이미지나 응답을
포함하지 않습니다.

비공개 원본 9장의 실제 검출 결과를 재생해 새 영역 정책과 후단을 확인합니다. 번역은
길이에 비례한 고정 시험 문자열로 대체하고, 실제 OCR·제거 모델과 식자 결과를 분리해
기록합니다. 검출 모델 재추론, ComfyUI executor/GPU, 실제 번역 품질을 검증한 것으로
확대하지 않습니다. 0개 식자·원본 보존·예산 중단·부분 결과를 전체 페이지 성공으로 세지
않으며 글자 누락과 인식 오류는 남을 수 있습니다.

설치 명령과 전체 회귀는 [개발 가이드](../development.md)를 따릅니다.

## 이번 버전 확인 결과

- CPU 회귀 822개를 통과했습니다. 처리 불가 문장의 원본 복원과 독립 영역 식자, 명시적 strict/stop 유지, 폴더 재개·캐시·패키지 계약을 함께 검사했습니다.
- 비공개 원본 9장에 RF/Hayai 및 PP 경로를 적용했습니다. 실제 검출 결과를 재생하고 이번 세션에서 생성한 실제 OCR의 동일 크롭·계획을 확인해 후단을 재실행했습니다. 최종 제거는 실제 Anime LaMa 21타일, 식자는 보존 조건을 포함한 51조건입니다.
- RF 경로는 9장 후단을 종료했지만 큰 제목/회전 표지 2장은 식자 0개로 원본 보존했습니다. PP 경로는 8장 후단을 종료하고 1장은 기존 검출 영역 예산 중단이 남았습니다. 이를 전체 페이지 성공률로 세지 않습니다.
- 설명문 대조에서는 PP 검출/OCR과 문단 묶기를 사용하고 `split_long_lines=False`로 비교했을 때 선택한 원문 6영역이 내용 일치하고 식자 3조건이 완료됐습니다. 다른 입력의 정확도를 보증하거나 Hayai 기본 설정을 바꾸는 결과는 아닙니다.

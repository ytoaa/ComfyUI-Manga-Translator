# v0.7.14 컷·말풍선 경계

첨부 실행 보고서에서는 19개 검출 중 r4·r6·r9가 보존됐고 미할당 획 1개가 추가 보존됐습니다. 식자 보고서는 16영역 처리와 4개 보존 항목입니다. 별도로 표시된 15/0 상태와 같은 실행이라고 확인할 근거는 없습니다.

r9는 여러 컷을 가로지르는 큰 세로 검출이었으며 검수 보호가 겹친 r4·r6로 전파됐습니다. 실제 보호 정책은 유지하고 앞단 검출 정리를 수정했습니다. 원시 검출 마스크·전체 컷 좌표가 첨부 보고서에 없어 동일 페이지의 추론 결과를 완전히 재생할 수는 없습니다.

## 구현과 검증 범위

- 잘리지 않은 컷 또는 말풍선 검출 사이의 간격을 중복 통합보다 먼저 적용합니다. 거의 동일한 소유 영역은 정리하며 겹치는 소유 영역은 빈 경계로 간주하지 않습니다.
- 원문 검출이 경계를 가로질러도 실제 마스크의 해당 구간이 완전히 비어 있고 양쪽에 획이 있어야 분리합니다. 분리 전후 모든 양성 픽셀 수와 합집합을 확인합니다.
- 경계 양쪽 검출을 다시 합치지 않습니다. 가로 행 조각 조건으로 인접 세로 문장이 합쳐지지 않도록 제한합니다. 중복 통합의 마스크는 실제 합집합으로 보존합니다.
- 검출 보고서 region_resolution에 boundary_partition.observations와 boundary_partition.separator_count를 기록합니다. 새 단계 캐시 버전에서 검출·OCR을 다시 계산해야 합니다.
- 마스크 없음·경계 속 실제 획·잘린 컷·겹친 컷·분할 자원 한도 위반은 자동 완화하지 않습니다. 근거가 부족하면 기존 검수 보존이 남습니다.

새 회귀는 첨부 r9 좌표와 합성 마스크·소유 영역을 사용합니다. 실제 만화 이미지·OCR·번역문은 공개하지 않습니다. 합성 분리 결과에서 원문 검수 보호가 해제되고 교체 계획으로 연결되는 조건, 가로/세로 경계, 부분 중복, 중첩 페이지, 비인접 컷, 말풍선 경계, 합집합 마스크와 오류 입력을 검사합니다.

운영 ComfyUI/GPU 전체 실행과 실제 모델 인식 정확도, 번역 정확도, 생성 배경 품질은 이 회귀의 보증 대상이 아닙니다. Chromium 실행 파일이 없는 환경이므로 실제 브라우저 검증도 포함하지 않습니다.

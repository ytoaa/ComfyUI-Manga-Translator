# v0.7.11 영역 검수와 수동 제거 보정

자동 처리 뒤 사람이 잘못된 영역과 마스크를 고치고 다시 실행하는 경로를 추가합니다. 검출/OCR 모델 교체나 페이지 전체 품질 인증이 아닙니다.

기능 흐름을 참고해 Python/ComfyUI용 코드를 독립 작성했습니다. 외부 Rust/Qt/GPL 코드·프롬프트·모델·폰트는 새로 포함하지 않았습니다. 기존 포함 코드의 고지는 [THIRD_PARTY_NOTICES](../../THIRD_PARTY_NOTICES.md)를 유지합니다.

## 편집 계약

- `review_edits_json`은 `pages[revision][region_id]`와 `identities[revision]`에 선택·획을 저장합니다. 폴더는 project/page 신원, 단일 노드는 원본 RGB 신원을 사용합니다. revision은 원본 float 픽셀과 RGB·원문/번역·좌표·마스크·보호 근거·정책을 포함합니다. 입력이 바뀐 편집은 자동 이월하지 않습니다.
- 브러시는 기존 편집 사각형 내부에만 적용합니다. 더 큰 편집 권한을 만들지 않으며, 파란 검출 원문 획은 erase로 제외할 수 없습니다. 보존 영역과 겹치면 수동 replace도 보호 전파를 해제하지 못합니다.
- 편집 명세·제거 마스크·식자가 같은 계획을 사용합니다. 수정 출처도 계획 digest에 포함하며 계획 뒤 변경하면 stale로 거부합니다. 폴더의 공통 설정 해시와 페이지 편집 해시를 분리하고 자동 실행의 설정 고정에 브러시도 포함합니다.
- 브러시는 원본 페이지 픽셀 좌표입니다. 축소 화면의 안티앨리어싱과 실제 정수 마스크는 같지 않을 수 있으므로 재실행 후 마스크 미리보기를 확인합니다. 기존 `region_actions_json`은 모든 페이지의 같은 ID에 적용하는 공통 설정으로 유지합니다.

## 검사

전체 CPU 회귀 **852 PASS (128.56초)**, 등록 파일 **171개**·로컬 문서 링크 **106개**, JS 노드 UI·캔버스 실행 계약 PASS입니다. 테스트 개수는 페이지 완성률이 아닙니다.

새 회귀 23개는 누락 획을 수동으로 지정한 실제 단색 제거, 사각형 밖 불변, 원문 획 지우기 거부, 보호 이웃 보존, 잘못된 좌표/반경/형식/예산 거부, stale 출처 거부, 페이지/프로젝트/원본/마스크/번역/기하/소유권/정책 변경, PNG 크기, 소유 페이지만 재처리하는 폴더 경로를 검사합니다. 모델·큐는 필요한 경우 명시적 대역입니다.

비공개 9개 원본의 PP/RF 저장 예측·수집 문서를 새 편집 노드로 실행한 18건에서, 무편집 시 이전 v0.7.10의 교체/보존 결정과 source/cleanup 마스크가 모두 정확히 일치했습니다. 원본 문맥 재복구와 UI 크롭 생성을 포함하며 새 검출/OCR/번역/생성 제거 추론은 실행하지 않았습니다. 사용자 이미지·원문·마스크·응답은 저장소에 포함하지 않습니다.

JS 계약은 페이지별 선택 저장·좌표 역변환·포인터 획 저장·취소·초기화·텍스트 escaping·노드 크기·기존 폴더 실행을 검사합니다. Canvas API는 대역입니다. 실제 Chromium CSS/포인터 검사는 브라우저 설치 파일이 유효한 ZIP으로 내려오지 않아 미완료입니다. 운영 ComfyUI/GPU 화면을 검증했다고 주장하지 않습니다.

## 남는 범위

자동 검출 누락·효과음의 전체 획 복원·미검출 영역 생성·레이아웃 드래그·마스크 밖 잔존 글자 판정·PSD 편집은 남습니다. 보정한 마스크가 실제 글자만 포함하는지와 생성된 배경의 품질은 사람이 검수해야 합니다. 같은 페이지 안에서 영역 하나를 고치면 페이지의 제거 계획을 다시 만들며 다른 타일까지 개별 선택 재생성하는 기능은 아닙니다. 검출/OCR/번역의 기존 체크포인트는 입력이 같으면 재사용할 수 있습니다.

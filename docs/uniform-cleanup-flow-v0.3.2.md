# v0.3.2 — 단색 잔상 보완과 가용 폭 우선 식자

사용자 화면에서 흰 잔점은 이미 `식자 직전 전체 배경`에 있었으므로 식자 합성 이전의 문제다.
화면만으로 실제 마스크 누락과 Qwen의 생성 잔상을 완전히 구분할 수는 없다.
기존 제거 검사는 원문 획 대부분이 그대로인 응답을 막았으며 소수의 잔점까지 보증하지 않았다.
또한 번역문의 단일 줄바꿈이 강제 유지되면 오른쪽 공간이 남아도 여러 줄을 넣기 위해 글자가 줄어들 수 있었다.

## 적용

업데이트 후 ComfyUI를 재시작하고 **08 JSON을 새로 가져온다**.
새 기본값과 추가 마스크 연결은 이미 열어 둔 캔버스에 자동으로 추가되지 않는다.
기존 노드와 출력 슬롯 0~7의 의미를 유지했고 새 커스텀 노드를 추가하지 않았다.

## 단색 text 영역 보완

08의 `MangaInpaintPlan`은 검출된 영역 JSON을 받아 `recover_uniform_ink=true`로 실행한다.
다음 조건을 모두 만족하는 text 사각형에서만 원본의 대비 획과 작은 점을 보완한다.

- 사각형 바깥 10px 주변에서 기존 제거 마스크를 제외한 표본 32개 이상.
- 주변 표본의 98%가 중간색 기준 RGB 최대 편차 0.018 이내.
- 영역 내부 65% 이상이 같은 색 기준 0.025 이내.
- 기존 검출 마스크가 실제 대비 픽셀 8개 이상이고, 전체 대비 픽셀의 15% 이상을 지지함.

영역은 원래 text bbox에서 2px 여유를 둔 범위다. RGB 최대 편차 0.035를 넘는 픽셀과
1px 획 여유, 해당 영역 안의 기존 제거 마스크를 배경색으로 채운다.
누락된 대비 획은 복구 원문 마스크에, 추가 삭제 범위는 실효 제거 마스크에 포함한다.
남은 GrowMask의 빈 단색 여유는 Qwen을 실행하지 않고 그대로 통과한다.
무늬·그라데이션·효과음 또는 지지 표본이 부족하면 기존 연결 요소/Qwen 경로를 유지한다.

이는 의미론적인 글자 판별기가 아니다. 잘못 검출된 text 사각형에 실제 그림이 함께 있다면
정상 그림도 대비 픽셀일 수 있으므로 원문 크롭과 실효 마스크를 검수한다.
text 영역 밖으로 밝은 점을 검색하거나, 페이지 전체에서 흰 픽셀을 지우지는 않는다.
`recover_uniform_ink=false`로 이번 보완만 끌 수 있고 `uniform_fill=false`는 단색 선처리 전체를 끈다.

Plan의 추가 출력:

- `effective_cleanup_mask`(8): 보완된 실제 삭제 허용 범위. 새 08의 제거 마스크 미리보기에 연결.
- `recovered_source_mask`(9): 보완된 원문 획. 새 08의 스타일 측정에 연결.

Plan/Assemble 보고서의 `uniform_region_recovery`는 영역별 채택 여부·거절 이유·배경색·보완 픽셀 수를 기록한다.
`cleanup_mask_pixels`는 입력 마스크, `effective_cleanup_mask_pixels`는 보완된 마스크의 픽셀 수다.
정확한 픽셀 보존 보장은 **실효 제거 마스크 밖**에 적용한다.

## 가용 폭 우선 식자

새 08의 식자 계획은 `line_breaks=reflow`다.
가로 source/bubble 모드에서 단일 줄바꿈을 물리적 줄바꿈으로 보고 연결한다.
빈 줄로 구분한 문단은 유지하고, 한국어/라틴 글씨의 경계에는 공백을 둔다.
일본어/CJK 연속 문자 사이에는 공백을 새로 넣지 않는다.
원래 식자 프레임의 가용 폭에서 원문 크기 상한부터 순서대로 배치를 시도한다.
행을 폭까지 채우는 greedy wrap을 사용하고 원문 행 수만을 이유로 먼저 축소하지 않는다.
최종 폰트는 원문 측정 크기 상한을 넘지 않으며, 타 영역과의 충돌·잘림 검사와 최소 크기는 유지한다.
페이지의 비어 보이는 오른쪽 전체를 임의로 점유하는 기능은 아니다.

입력의 수동 줄바꿈을 유지할 때는 노드의 `line_breaks=preserve`, 또는 영역별로:

```json
{"r1":{"line_breaks":"preserve"}}
```

strict 모드와 세로쓰기는 reflow를 지정해도 줄바꿈을 유지한다.
기존 함수/그래프 기본값은 preserve로 유지했다. 번역 JSON의 target 문자열은 수정하지 않고
식자 보고서에 원래 문자열과 렌더링 문자열을 모두 남긴다.
줄바꿈에 의미가 있는 시·제목·대사는 preserve를 사용한다.

복구한 작은 점/분리된 문장부호를 글자 한 행으로 세면 크기 추정이 낮아질 수 있어,
대표 행 높이의 45%보다 작은 밴드는 글자 크기와 행 수 추정에서 제외한다.
해당 픽셀 자체를 원문 마스크에서 삭제하는 것은 아니다.

## 검증과 한계

실제 동봉 폰트 재현에서 같은 프레임의 `23px / 2행`이 reflow에서는 원문 상한 `27px / 1행`이 됐다.
합성 회색 배경의 검출 마스크에서 누락시킨 흰 점 13픽셀을 복원했고 영역 밖의 같은 흰 그림은 유지했다.
무늬 배경 거절, 잘못된 좌표 거절, 지지 획 부족, Qwen 비교 경로, 문단/수동 줄바꿈 보존도 확인한다.
배포 08 그래프에서 원문 마스크에 없는 3×3 흰 점을 주입해 식자 전 배경에서 제거되는 경로를 검사한다.

이는 CPU 픽셀/폰트 검사와 모델 대역 모의 실행이다.
사용자 원본의 실제 RF-DETR/Hayai/Qwen GPU 응답을 다시 실행한 결과는 아니며,
그라데이션·스크린톤의 소수 잔상이나 잘못 검출된 글자를 모두 해결했다고 주장하지 않는다.

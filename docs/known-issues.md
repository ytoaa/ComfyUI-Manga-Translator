# 알려진 한계와 후속 작업

현재 처리 버전은 v0.7.1입니다. 지원 범위와 아직 검증이 부족한 동작을 기록합니다.

## 추가로 재현된 전이 경계

0.7.1의 기존 수용 검사와 별도로 추가 37개를 실행해 12가지 원인의 실패 경로를 확인했습니다. [새 전이·경계 감사](validation/README.md)에 조건과 증거를 기록했으며, 운영 코드는 아직 이 감사 결과를 반영해 수정하지 않았습니다.

- 자동 연속 실행의 페이지 사이에서 공통 설정을 바꾸면 그래프·프로젝트 설정이 어긋나 결과 수집이 중단될 수 있습니다. 현재 run이 끝나거나 중지·결과 수집이 끝난 뒤 새 수동 실행으로 설정을 바꾸세요.
- 활성 페이지에 같은 run_id의 연속 요청을 재전송하면 원래 실행도 일시정지될 수 있습니다. 일반 새 시작의 두 탭 방어와 별도의 경로입니다.
- 공유 캐시 갱신과 모델 파일 교체를 실행 중에 하면 값·진단 세대 불일치, 이전 메모리 모델 사용 또는 lazy 입력 중단이 발생할 수 있습니다. 실행 중 모델 교체는 피하고 교체 후 ComfyUI를 재시작하세요.
- 긴 다문단의 페이지 확정, 부모별 중복 블록 ID, 전체 JSON 예산과 blocks=[]의 검증 계약에 남은 불일치가 있습니다.
- 모델 첫 자동 설치를 여러 ComfyUI 프로세스에서 동시에 실행하면 한쪽이 설치 완료 뒤 오류를 낼 수 있습니다. 설치된 모델 해시는 보존됩니다.
- 균일 RGB 생략은 작은 잡음·그라데이션·선·점만 있는 비문자 입력의 OCR 환각을 막지 못합니다. 품질 검사가 이를 정답으로 인증하지 않습니다. NaN/범위 밖 IMAGE 입력의 빈 크롭 판정도 보완이 필요합니다.

일반 회귀 통과가 이 새 경로의 성공을 의미하지 않습니다. 백만 번째 attempt 번호 재사용 같은 낮은 빈도의 경계도 별도 기록했습니다.

## 조판과 검수

- 회전된 로컬 frame과 블록별 식자는 지원합니다. 모든 글자 영역의 제목/본문/보조 역할을 자동으로 판정하지 않습니다. 확인된 행 높이 차이가 없는 영역은 하나로 유지합니다.
- 원문이 애초에 잘렸거나 기하가 불확실하면 보존·검수로 돌아갑니다. 회전 조판이 미검출 문단을 복원하지는 않습니다.
- 노드 안 텍스트 검수와 표현 JSON을 지원합니다. 페이지 위 직접 드래그하는 완전한 레이아웃 편집기·마스크 페인팅·rich text 편집기는 아닙니다.
- 원문 아래 여유를 임의로 넓히지 않습니다. 말풍선/보존/충돌 제약 때문에 번역이 맞지 않을 수 있습니다.
- 검수 수정은 워크플로우 위젯에 저장되며 최대 256개의 입력 revision을 지원합니다. 대형 책의 검수 내보내기/가져오기와 편집 이력 관리 UI는 후속 과제입니다.

## 인식·번역

- 표지·복잡한 카드·효과음·작은 글자·손글씨를 모두 안정적으로 검출/인식하지 못합니다.
- 기하 복구는 이미 관측한 글줄의 빠진 획을 찾습니다. 미검출 문단 전체를 복원하거나 정답 원문을 추측하지 않습니다.
- 효과음 분류는 의미 정답이 아니며 include_sfx=false에서 실제 본문이 제외될 수 있습니다.
- 반복·누락·미인식 검사는 OCR 정확도 점수가 아닙니다. 정상 종료한 원문에도 오독이 남습니다.
- 명시적 용어집과 사람이 확정한 이전 페이지를 문맥으로 사용합니다. 책 전체 사전/요약을 자동으로 작성하지 않습니다.
- 폰트 자동 식별·완전한 원본 글자체 복제·자동 곡선 복원은 지원하지 않습니다.

## 검증 범위

실제 RF-DETR/Hayai CPU 추론은 특정 첨부 입력·고정 가중치 조건에서 수행했습니다. 일반 정확도·CPU/GPU 동등성·DGX 처리 속도 측정이 아닙니다. Qwen 제거·실제 번역 서버·GPU 최종 식자를 포함한 전체 페이지 품질은 별도 검수가 필요합니다. [검증 자료](validation/README.md)에서 실제 추론과 합성/대역 회귀를 구분합니다.

자동 처리 뒤에도 [사용법의 상태](usage.md)와 [중간 결과](troubleshooting.md)를 확인합니다.

# 알려진 한계와 후속 작업

현재 처리 버전은 v0.7.20입니다. 지원 범위와 아직 검증이 부족한 동작을 기록합니다. 전체 코드·사용 경로 검토는 [진행 중인 감사 기록](validation/full-system-audit.md)에서 완료한 검사와 남은 검사를 구분합니다.

현재도 작은 원문·저대비 입력의 6가지 식자 조건과, 일부 원문 잔존·틀린 배경색을 받아들이는 2가지 제거 출력 조건이 미해결입니다. [적대적 검사](validation/adversarial-ownership.md)의 8 GAP을 번역 성공으로 계산하지 않습니다. 실제 사용자 페이지의 원시 검출 마스크·OCR·번역 응답으로 전체 경로를 재실행한 검증도 필요합니다.

0.7.17–0.7.18은 확인된 말풍선 내부와 원문 획 소유권을 이용해 일부 겹친 관측을 분리·통합합니다. 모든 중복·모호한 관측을 자동 복구하지는 않습니다. 0.7.19–0.7.20은 캐시 진단 손실·오류 복구·연속 실행·업로드·저장 경로를 수정하며, OCR/번역 의미 정확도나 배경 복원 품질 개선의 증거는 아닙니다. 실제 ComfyUI 브라우저·GPU·운영 번역 서버와 연결한 전체 검증은 이번 로컬 계약 검사에 포함되지 않습니다.

## 이전 버전에서 관측한 제한

아래 버전별 문단은 당시의 관측과 제한입니다. 현재 수정 범위는 위 요약과 [변경 기록](../CHANGELOG.md)을 함께 확인합니다.

0.7.7은 동일 좌표·동일 양의 분할 마스크를 가진 일반 텍스트/효과음의 중복만 합칩니다. 다른 마스크나 단순한 크롭 중복, 모델의 철자 오독까지 해결하지 않습니다. 추가 생성 입력에서 글자 없는 평행선이 `IIIIIII`로 수집되는 오검출·환각을 확인했습니다. 기울어진 글씨는 검출 기하가 불확실해 원본 보존으로 남을 수 있습니다.

작은 원문(추정 9px)과 저대비 입력의 기본 식자는 중단될 수 있습니다. 합성의 원문 잔존 휴리스틱은 절반 남은 원문·잘못된 배경색을 모두 거부하지 못합니다. [추가 이미지 검사](validation/expanded-images.md)에 실제 모델과 주입 조건을 구분해 기록합니다.

0.7.6은 OCR 후 추가 보호 영역을 식자가 거부하던 오류를 수정합니다. 번역을 고정 시험 문장으로 제외한 검사에서도, 무늬 배경의 실제 Qwen 제거는 별도 실행이 필요합니다. 단색으로 제거한 일부 영역의 정상 식자를 전체 이미지 합격으로 계산하지 않습니다. 서로 겹친 검출 크롭에 같은 원문이 들어가는 문제도 남습니다.

0.7.5는 보존 영역과 겹친 선택적 크롭 여백을 줄이며, 본문 밖 사이드바 때문에 다단 분리가 기권하는 경로를 개선합니다. 본문 안의 미배정 영역·불확실한 단 간격에는 적용하지 않습니다. OCR `failure_policy=preserve_review`는 재시도 후 거부된 영역 전체와 겹친 편집 영역을 원본 보존·검수합니다. 읽기 성공이나 전체 번역 완료를 뜻하지 않습니다. 철자 누락·무관한 정상 문장, 검출되지 않은 작은 본문·장식 제목, 일부 중복 크롭은 여전히 남습니다.

## 이웃 식자 충돌의 처리 범위

0.7.4는 앞 문단이 뒤 문단의 원문 공간을 차지하는 경로를 제한하고, 기존 허용 마스크 안의 빈 사각형에서 완전한 번역문을 다시 조판합니다. 겹친 원문 프레임의 중심 거리 분할은 배치 규칙이며 검출 소유권/원문 정확도의 증명이 아닙니다. 페이지 전체의 글자를 동시에 옮기는 최적화도 아닙니다.

같은 중심의 중복/불확실한 원문, 회전 로컬 프레임에서만 가능한 재배치, 최소 크기로도 맞지 않는 문장은 계속 실패할 수 있습니다. 실패 메시지의 conflicting_region_ids와 원문/번역/계획 보고서를 함께 확인합니다. 이번 첨부본은 1426×2048 RGBA이며 로그는 더 큰 페이지의 좌표입니다. 당시 실제 번역 JSON·계획·검출 마스크가 없어 동일 페이지의 GPU 전체 재실행 성공으로 주장하지 않습니다.

## 전이 경계 수정과 남은 범위

0.7.1 추가 감사에서 확인한 12가지 원인의 경로는 0.7.2에서 실행 소유권·캐시 세대·문서 계약·OCR 입력 근거로 묶어 수정했습니다. [검증 기록](validation/README.md)은 당시 발견과 수정 후 검증을 구분합니다.

- 자동 연속 실행 도중 공통 처리 설정을 바꾸면 해당 요청만 거부합니다. 현재 페이지의 결과를 수집하고 연속 실행을 멈춘 뒤 새 수동 실행으로 변경하세요.
- 캐시 lazy 적중이 선택한 모델 파일 세대는 그 호출이 소비할 때까지 고정됩니다. 다음 적중 검사부터 새 파일 세대를 사용합니다. 추론 중 로컬 모델 파일 교체는 명시적 오류로 막습니다.
- 캐시 저장이 값 교체 후 manifest 교체 전에 중단되면 해당 캐시는 miss가 되어 재계산합니다. 캐시는 프로젝트 결과의 대체 저장소가 아닙니다.
- 문서 전송은 전체 2,000,000자, 식자 입력은 UTF-8 8 MiB로 제한됩니다. 개별 문단 예산을 모두 채운 조합도 전체 예산 검사를 통과해야 합니다.
- 약한 OCR 입력 검사는 정확도 판별기가 아닙니다. 점 하나·선처럼 글자일 가능성이 남은 입력은 원본을 보존해 검수합니다. 실제 글자가 있는지 알 수 없는 그림 전체의 환각까지 해결하지는 않습니다. 품질 검사 해제 시 이 추가 생략 정책은 적용하지 않습니다.
- 실제 브라우저 두 탭·GPU 전체 실행·네트워크 파일시스템·전원 단절 뒤 내구성은 이번 CPU 계약 검사로 보증하지 않습니다.

## 실제 페이지에서 확인한 후속 범위

0.7.3은 말풍선 소유권 오류의 지역 보존·폴더 검수 전파, 번역 길이 초과의 제한된 ID 분할 복구, 노드 DOM 크기 계약을 수정했습니다. 실제 첨부 페이지의 검출 말풍선 마스크와 번역 실패 응답 원문은 제공되지 않아 해당 마스크의 분할 원인이나 서버 출력 반복을 확정하지 않았습니다. CPU 회귀의 마스크·API·큐는 대역이며 실제 모델 품질 보증이 아닙니다.

- 제공된 번역 실패 페이지 OCR은 9개 영역·123자이지만 생성은 4,096토큰/8,203자였습니다. 원문 길이만으로 원인을 설명할 수 없으며 서버 원시 응답·chat template 검토가 남습니다. 같은 페이지 상단의 겹친 영역/부분 중복 OCR도 별도 문제로 남습니다.
- 말풍선 보존 정책은 불확실한 영역을 번역 완료로 만들지 않습니다. 실제 마스크 소유권 교정과 인식 원문 검수가 필요합니다.
- UI 크기/스크롤 계약은 DOM 대역으로 검사했습니다. 휴대 가능한 Chromium 검사 도구는 추가했지만 이번 환경은 브라우저의 Unix socket 생성이 거부돼 실제 CSS 검사와 운영 ComfyUI 화면 검증을 완료하지 못했습니다.

## 조판과 검수

- 회전된 로컬 frame과 블록별 식자는 지원합니다. 모든 글자 영역의 제목/본문/보조 역할을 자동으로 판정하지 않습니다. 확인된 행 높이 차이가 없는 영역은 하나로 유지합니다.
- 원문이 애초에 잘렸거나 기하가 불확실하면 보존·검수로 돌아갑니다. 회전 조판이 미검출 문단을 복원하지는 않습니다.
- 노드 안 텍스트 검수와 표현 JSON, 기존 편집 사각형 안의 제거 마스크 브러시를 지원합니다. 페이지 위 직접 드래그하는 완전한 레이아웃 편집기·미검출 영역 생성·rich text 편집기는 후속 과제입니다. 브러시 보정은 자동 효과음 완성이나 생성 배경 품질의 보증이 아닙니다.
- 원문 아래 여유를 임의로 넓히지 않습니다. 말풍선/보존/충돌 제약 때문에 번역이 맞지 않을 수 있습니다.
- 검수 수정은 워크플로우 위젯에 저장되며 최대 256개의 입력 revision을 지원합니다. 대형 책의 검수 내보내기/가져오기와 편집 이력 관리 UI는 후속 과제입니다.

## 인식·번역

- 표지·복잡한 카드·효과음·작은 글자·손글씨를 모두 안정적으로 검출/인식하지 못합니다.
- 기하 복구는 이미 관측한 글줄의 빠진 획을 찾습니다. 미검출 문단 전체를 복원하거나 정답 원문을 추측하지 않습니다.
- 효과음 분류는 의미 정답이 아니며 include_sfx=false에서 실제 본문이 제외될 수 있습니다.
- 반복·누락·미인식 검사는 OCR 정확도 점수가 아닙니다. 정상 종료한 원문에도 오독이 남습니다.
- 명시적 용어집과 사람이 확정한 이전 페이지를 문맥으로 사용합니다. 책 전체 사전/요약을 자동으로 작성하지 않습니다.
- 폰트 자동 식별·완전한 원본 글자체 복제·자동 곡선 복원은 지원하지 않습니다.

## 검증 범위

실제 RF-DETR/Hayai CPU 추론은 특정 첨부 입력·고정 가중치 조건에서 수행했습니다. 일반 정확도·CPU/GPU 동등성·DGX 처리 속도 측정이 아닙니다. Qwen 제거·실제 번역 서버·GPU 최종 식자를 포함한 전체 페이지 품질은 별도 검수가 필요합니다. [검증 자료](validation/README.md)에서 실제 추론과 합성/대역 회귀를 구분합니다.

자동 처리 뒤에도 [사용법의 상태](usage.md)와 [중간 결과](troubleshooting.md)를 확인합니다.

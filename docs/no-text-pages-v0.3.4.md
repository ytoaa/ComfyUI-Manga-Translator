# 검출된 글자가 없는 페이지 (v0.3.4)

새 08은 선택한 글자 영역이 0개면 오류 대신 원본 페이지를 그대로 저장한다.
검출 자체는 전체/상세 검출 정책대로 수행한다. `page_status=no_text_detected`는
**선택된 글자 검출이 없음**을 뜻하며, 실제로 글자가 전혀 없음을 보증하지 않는다.
검출 누락이 있는 페이지도 원본을 보존하므로 검수 시 구분해야 한다.

## 실행 경로

- 영역 JSON의 명시적 `regions: []`를 허용한다. 영역 필드 누락·잘못된 검출 응답은 오류다.
- 08의 `MangaRegionCrops.allow_empty_page=true`와 OCR `manifest_json` 연결을 함께 사용한다.
  빈 ComfyUI 이미지 목록으로 후속 매핑이 깨지지 않도록, 이 경우 원본 한 장을 미리보기로 전달한다.
  이 이미지는 OCR 영역으로 인식하지 않는다. 두 OCR 미리보기의 제목에도 원본 통과임을 표시한다.
- Adaptive OCR은 페이지 명세를 먼저 검사하고 Hayai 로더의 lazy 링크를 요청하지 않는다.
  반환하는 빈 텍스트는 0개 영역 페이지의 전송용 값이며, 실제 검출 영역의 빈 OCR은 여전히 오류다.
- OCR/번역 JSON에 빈 영역 목록과 `page_status=no_text_detected`, 생략 상태를 저장한다.
  번역은 모델 조회와 번역 HTTP 요청을 모두 생략한다.
- 글자 마스크와 제거 마스크는 0이다. 기존 타일 집계의 lazy 경로가 Qwen 로더·샘플러를 생략한다.
  식자 계획/적용은 빈 영역을 받아 원본 이미지와 0 알파를 반환한다. 기본 SaveImage는 정상 실행한다.
- 말풍선/패널만 있는 페이지, 기본 설정에서 제외된 효과음만 있는 페이지도 같은 경로다.

검출 예외, 미해결 타일 경계, 토큰 한도 재시도 실패, 실제 영역의 빈 OCR,
불완전한 번역은 무문자 페이지로 바꾸지 않고 계속 중단한다.

## 업데이트와 호환성

`git pull` → ComfyUI 재시작 → **새 08 JSON 불러오기**.
기존 저장 그래프에는 페이지 명세 연결이 없으므로 파일만 업데이트해서는 새 생략 경로가 생기지 않는다.
기존 크롭 노드의 `allow_empty_page` 기본값은 false로 두었다. 오래된 연결에서
빈 페이지 전체를 OCR하게 만드는 대신, 새 08을 불러오라는 명확한 오류를 낸다.
영역이 있는 기존 그래프는 원래 동작을 유지한다.

## 검증

실제 커스텀 노드·CPU 텐서로 배포 08 API 그래프의 모든 저장/미리보기 출력을 실행했다.
무문자, 말풍선만 있음, 제외된 효과음만 있음의 세 경우에서 원본/최종 PNG 픽셀 동일,
Hayai/Qwen 로더 미실행, OCR·Qwen 추론 0회, 번역 HTTP 0회, JSON/이미지 저장을 검사한다.
검출 실패가 최종 저장에 도달하지 않는 것과 명세 크기 불일치·가짜 OCR 값 거부도 검사한다.
모델 응답은 대역이며 실제 사용자 ComfyUI/GPU 실행은 별도 확인 대상이다.

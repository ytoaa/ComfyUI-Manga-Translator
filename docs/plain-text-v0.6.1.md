# v0.6.1 텍스트 경계 계약

첨부 자료의 OCR 원문은 실제 개행을 포함했으나 번역 응답은 `<br>`로 바꿨다. 기존 식자는 이를 문자로 그렸다. 별도로 OCR 한 행의 `<UNK_SPAN>`도 issue=null로 통과하여 번역과 출력에 남았다. 각도 보정과 행 분할이 수행되더라도 인식 정확도가 보장되는 것은 아니다.

번역 시스템 지시는 HTML/Markdown 없이 JSON 문자열의 `\n`으로 줄바꿈을 표현하도록 명시한다. 원문에 break 태그가 없을 때만 응답의 `<br>`, `<br/>`, `<br />` 및 대소문자 변형을 실제 개행으로 바꾼다. 일반 HTML 파싱·태그 제거·엔티티 해제는 수행하지 않는다. 원문 자체에 break 태그가 있거나 `translated_override_json`을 수동 입력한 경우 문자를 그대로 보존한다. break 태그만 있어 변환 후 공백뿐인 답변은 거부한다.

변환된 영역의 `translation_diagnostics`에는 `raw_target`, `html_breaks_to_newlines`, 의미 정확도 검사가 아니라는 scope를 기록한다. 통합 08의 번역/제거 계획 JSON 미리보기에서 확인할 수 있다. 콘솔에는 영역 ID와 변환 개수만 기록한다.

`<UNK_SPAN>`은 일반 문자나 신뢰도로 취급하지 않는다. 적응형 OCR에서 패치 예산을 한 차례 바꾸어 재인식하며, 기존 설정에 따른 검증된 레이아웃 복구 경로도 사용한다. 끝내 해결되지 않으면 `ocr_unrecognized_span`으로 원본 크롭·입력·응답·시도 내역을 기존 OCR 실패 디렉터리에 저장하고 중단한다. 이 명시적 미인식 검사는 `quality_guard=false`에서도 적용된다. 반복·누락 같은 휴리스틱 검사 설정은 별도로 유지한다.

오래된 OCR JSON에 같은 표시가 있으면 번역 API 호출 전에 거부한다. 검수자가 전체 영역의 번역을 수동으로 확정해 override를 제공하는 것은 허용하지만 그 번역에 미인식 표시가 남아 있으면 거부한다. 식자 입력도 마지막으로 검사한다. 미인식 부분을 삭제하거나 추측해서 채택하지 않는다.

업데이트 후 ComfyUI를 재시작한다. 그래프와 위젯 값은 v0.6.0 그대로이므로 기존 프로젝트를 새로 만들 필요는 없다. 이미 완료된 페이지는 자동 재처리하지 않으므로 문제 페이지를 단일 이미지 모드로 다시 실행하거나 새 프로젝트 이름으로 폴더를 재실행한다. 실패 재시도는 실패 상태인 페이지만 선택한다.

이 수정은 표시 규약과 실패 경로를 고친다. 카드의 남은 OCR 오독, 효과음 분류, 배경 복원, 영역 배치 품질까지 해결했다는 뜻은 아니다. 실제 사용자 GPU 추론은 별도 재실행이 필요하다.

# 원문 보존 통합 식자

08 워크플로의 제거·좌표 복원 뒤에 `MangaLetterPlan`과 `MangaLetterApply`를 연결했다.
기존 01~07 예제와 기존 식자 노드는 호환을 위해 유지한다.

## 사용

저장소를 업데이트하고 ComfyUI를 재시작한 뒤 **08-integrated-tiled-cleanup-lettering.json을 새로 가져온다**.
기존 08을 열어둔 상태에서는 새 노드와 연결이 자동으로 추가되지 않는다.
원본, 모델과 번역 서버를 선택하고 실행한다. 크롭·스케일·제거 마스크 확대·타일 합성·저장은 기존 기본 노드를 사용한다.

식자 계획의 기본 모드는 `source`다. 원본과 지운 배경의 차이에서 원문 행/열 높이와 방향·정렬을 추정하고,
선택한 한글 폰트의 실제 가시 높이로 환산하여 크기 상한을 만든다.
짧은 번역문도 이 상한보다 커지지 않는다. 원문 행/열 수를 지키며 먼저 축소하고,
가독성 하한까지 맞지 않을 때 같은 프레임 안에서 줄바꿈을 다시 탐색한다.
최소 크기는 `max(min_font, ceil(원문 크기 상한 × min_scale))`다.

- `source`: 원래 편집 프레임 안에서 축소, 이후 재배치.
- `strict`: 원문 행/열 수 상한을 유지. 안 맞으면 오류.
- `bubble`: 위 탐색이 실패하면 연결한 실제 말풍선 내부 마스크에서 검증한 사각형으로 확장.
  내부 마스크가 없거나 원문 프레임을 둘러싸지 않으면 source 범위만 사용하고 보고서에 이유를 남긴다.

말풍선 마스크는 흰색=안전한 내부, 검정=테두리·꼬리·그림·외부다.
원문 글자 마스크와 다른 입력이며 사각형이나 이미지 밝기를 말풍선으로 자동 간주하지 않는다.
계획 미리보기의 주황색은 원래 프레임, 청록색은 검증된 확장 후보다.

## 영역별 조정

계획 노드의 `region_options_json`에서 실제 OCR/번역 JSON의 ID를 사용한다.

```json
{
  "r1": {"font": "NanumGothic-Bold.ttf", "font_cap": 32, "alignment": "center"},
  "r2": {"direction": "vertical_rtl", "min_font": 12, "min_scale": 0.6},
  "r3": {"direction": "horizontal", "rotation": 8, "shear": 0.1, "bend": 10},
  "r4": {"mode": "strict", "max_lines": 2, "line_spacing": 1.1}
}
```

`font_cap`는 사용자가 지정한 상한으로 자동 측정을 덮어쓴다. `padding`, `tracking`도 영역별 설정 가능하다.
획색·외곽선·질감·그림자는 기존 MangaLetterPrepare의 `region_options_json` 안 `style`로 지정한다.
기존 영역별 `font/layout/style` 설정도 전달된다.
글자를 줄일 때 외곽선·보정 획·그림자 크기도 같은 비율로 줄인다.
계획과 적용 노드의 보고서 STRING에는 측정값, 실제 폰트 크기, 축소율, 방향, 재배치 단계와 경고가 들어 있다.

## 세로·회전·곡선

`auto` 방향은 원문 픽셀 행/열의 휴리스틱이다. 애매한 혼합 문단이나 회전 글씨는 영역별로 지정한다.
`vertical_rtl`은 오른쪽 열부터, `vertical_ltr`은 왼쪽 열부터 읽는다.
CJK 문자는 세워 쓰고, 연속 라틴 문자열은 회전하며, 독립된 두 자리 숫자는 한 셀에 가로로 배치한다.
폰트에 해당 글리프가 있으면 세로 문장부호 대체 문자를 사용한다.
이는 완전한 OpenType vert/vrt2 조판 엔진이나 모든 언어의 정교한 문장부호 처리와 동등하지 않다.
폰트가 번역문을 지원하지 않으면 대체 네모를 쓰지 않고 오류로 알린다.

회전·기울기·포물선 형태의 `bend`는 수동 설정이다. 곡선 여백을 먼저 확보하고 변형 후 실제 알파 경계를 검사한다.
자동 효과음 곡선 추정·원본 폰트 식별·메시 편집은 포함하지 않는다.

## 실패와 검수

이웃 번역문 알파와의 충돌, 최소 크기에서의 넘침은 최종 저장 전에 중단한다.
번역문을 잘라 넣거나 무제한 축소하지 않는다. 보고된 ID에서 텍스트·방향·상한·프레임을 검수한다.
원문 제거 마스크는 새 글자 알파로 쓰지 않는다. 새 글자는 독립된 폰트 알파로 합성하고 그 밖의 배경을 그대로 보존한다.
이 기능은 OCR 반복·오인식, 번역 문맥 오류, 제거 잔상을 고치지 않는다.

## 검증

검증은 동봉 폰트의 실제 CPU 렌더링과 배포 API 그래프의 합성 입력 모의 실행이다.
실제 사용자 원본의 RF-DETR/Hayai/vLLM/Qwen 추론 품질, GPU 성능, 새 노드의 실제 ComfyUI 브라우저 실행은 별도 확인 대상이다.

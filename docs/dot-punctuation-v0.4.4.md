# v0.4.4: 점 나열의 개수와 원본 모양 보존

## 실제 입력

v0.4.3의 실제 폴더 보고서는 completed 10 / needs_review 5 / unchanged_blank 2 / failed 1이었다. 04/09/11은 미복구 경계의 원본 보존 결과를 저장했다. 08은 다음 OCR 입력에서 실패했다.

- `ocr_241871104ffb4440a40b990be98acede_input.png`: 34×268px, 세로 점 9개.
- Hayai patch 512의 결과 길이 15, patch 256의 결과 길이 12. 최종 rejected_text는 `・` 12개였다. 품질 검사가 short_repetition으로 거부했다.
- 원본은 실제 반복 기호였지만 생성 모델이 개수를 늘려 읽었다. 단순히 반복 경고를 해제하면 원본과 다른 개수를 통과시키게 된다.

첨부 원본·진단은 저장소에 포함하지 않는다.

## 제한된 기하 판독

`MangaOCRAdaptive`의 기존 quality_guard가 켜진 경우에만 적용한다. 최대 262,144px의 가로/세로로 긴 입력 전체에서 3~24개의 분리된 점을 확인한다. 모든 성분이 비슷한 크기의 속이 찬 둥근 형태이고, 한 축으로 정렬되며 간격이 일정해야 한다. 점 사이 거리, 배경의 균일한 비율, 테두리 여유도 확인한다. 작은 성분을 임의로 버리지 않는다.

이 조건을 만족하면 Hayai 생성 호출 대신 관측한 개수만큼의 `・`를 기록하고 `ocr_diagnostics.verified_punctuation`에 개수·방향·성분 좌표를 남긴다. 일반 글자 OCR이나 문장 의미 판정 기능이 아니다. 점을 포함한 혼합 문장, 구멍이 있는 글리프, 선·사각형, 약한 대비, 잡점, 불규칙 간격, 잘린 점, 범위 밖 개수는 기존 OCR 경로를 유지한다.

품질 검사도 원본에서 확인한 개수와 정확히 같은 점 문자열만 반복 예외로 인정한다. 9개가 있는 이미지에 12개 결과를 통과시키거나, 한자·단어 반복 검사와 토큰 한도 검사를 끄지 않는다. quality_guard=False의 기존 Hayai 경로는 유지한다.

## 번역·식자

검증된 점 문자열은 번역 모델에 보내지 않고 target을 source와 같게 유지한다. 다른 대사가 있는 페이지는 대사만 번역 요청에 포함하고 모든 원래 ID와 순서를 복원한다. 점만 있는 페이지는 번역 API 호출을 생략한다. 사용자 translated_override_json은 계속 우선한다.

`MangaLetterPrepare`는 source와 target이 같은 검증된 점 영역을 `preserved_punctuation`으로 전달한다. 통합 식자와 기본 스타일 식자는 이 영역에 새 폰트 글자를 그리지 않고 원본 픽셀을 복원한다. 통합 식자는 다른 번역문 alpha의 침범도 거부한다. 배치 검수 미리보기의 파란 사각형이 원본 점 보존 영역이다. 수동 번역 override로 target을 바꾸면 보존을 해제하고 기존 식자 경로를 사용한다.

기존 경계 보존에 의한 needs_review 상태는 유지한다. 점 개수 판독을 다른 대사의 OCR·번역 정확도 보증으로 사용하지 않는다.

## 적용·검증

통합 08의 노드 연결·위젯·설정 fingerprint는 변경하지 않았다. git pull 후 ComfyUI 재시작과 브라우저 새로고침, 같은 프로젝트의 실패 재시도로 남은 08 한 페이지만 새 시도를 만든다. 이미 완료/검수/원본 유지인 페이지와 이전 시도 파일은 보존한다.

첨부 34×268 실제 PNG를 CPU 노드에 넣어 관측 9개, Hayai 생성 호출 0회, 번역 호출 0회, 식자 후 원본과 픽셀 단위 동일함을 확인했다. 실제 크롭을 사용한 이 검증은 전체 08 페이지의 RF-DETR/Hayai/Qwen GPU 재실행이 아니다. 실제 전체 페이지의 후속 OCR 영역과 제거·식자 성공 여부는 DGX 재시도 후 확인해야 한다.

합성 회귀에는 가로/세로·밝은/어두운 점, 잘림·잡점·혼합 문자·비정렬·개수 한도 거부, 9→12 개수 불일치 거부, 일반 문자 반복 유지, 혼합 페이지 ID 보존, 수동 override, 원본 픽셀 복원과 품질 검사 끄기의 기존 동작을 포함한다.
